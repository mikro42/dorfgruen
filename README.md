# Dorfgrün

Ein Aufbauspiel im Stil von Siedler und FoE. - Nur viel einfacher aufgebaut, sorry.
Es gibt mehrere Level, die in eine kleine Geschichte eingebettet sind.
In jedem Level muss eine bestimmte Ware in ausreichender Anzahl hergestellt werden. Die Waren werden in verschiedenen Produktionsketten hergestellt. Voraussetzung ist Wohnraum, Nahrung, Werkzeug, ...
Die Zeit zur Erreichung des Ziels ist begrenzt.

Implementiert wurde als html mit JavaScript. Die Ausführung des Spiels erfolgt direkt hier im Browser:
