# Dorfgrün

Ein Aufbauspiel im Stiel von Siedler und FoE. - Nur viel einfacher aufgebaut.
Es gibt mehrere Level, die in eine kleine Geschichte eingebettet sind.
In jedem Level muss, mit Hilfe aufeinander aufbauende Produktionsketten eine bestimmte Ware in ausreichender Anzahl hergestellt werden.
Die Zeit zur Erreichung des Ziels ist begrenzt.

Implementiert wurde als html mit JavaScript. Die Ausführung des Spiels erfolgt direkt hier im Browser:
<a href="https://mikro42.github.io/dorfgruen/dorfgruen.html" target="_blank">▶️ Dorfgruen ausführen</a>

Implementiert wurde das Spiel komplett lokal durch die kleine KI Qwen3.8_27B auf einem PC mit 32GB DDR4 RAM und NVIDIA RTX GPU.
Es waren etwa 60 Prompts erforderlich, in denen ich das Spiel Schritt für Schritt bis zum aktuellen Stand entwickelt habe.
